This file is an example. It exists so the posts index, the post page, and the RSS feed have something to render. Delete it when a real post is ready.

## What to edit

Posts are Markdown or MDX files in `src/content/posts`. Each file needs a title, a description, and a publication date. Tags and draft are optional.

Set `draft: true` to keep a post out of the production build, the post index, and the RSS feed. Drafts still show up while `npm run dev` is running.

## A short list

The layout is meant to stay readable with only a few posts.

- One post is enough to check the page.
- Two or three posts should still look complete.
- There is no tag index, search, or comment thread.
